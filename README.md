# Daily Quotes 🌱

A simple daily journal of quotes, ideas, and short reflections.

The goal is to collect one meaningful quote each day and record a small reflection about why it matters.

## 📅 Daily Entries

| Date | Category | Quote |
|---|---|---|
| 2026-10-02 | Motivation | "The secret of getting ahead is getting started." |
| 2026-10-03 | Inner Peace | "Light does not defeat the night; it simply makes the dark visible." |

## 📂 Structure

```text
quotes/       → One Markdown file for each day
categories/   → Quotes grouped by theme as the collection grows
```

## ✍️ Daily Format

Each entry contains:

- Date
- Quote
- Author
- Category
- Short personal reflection

## 🎯 Goal

Build a consistent habit of reading, reflecting, and documenting one idea every day.

> Small progress, repeated consistently, compounds.
